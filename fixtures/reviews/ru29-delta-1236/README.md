## Что исправлено и что ещё требует приёмки

- F2: только missing + mind_realm разрешает создание, не Realm not found.
- F3: отрицательные контроли вызывают общий checker и проверяют его отказ.
- F4: REALITY заявляет наличие формулировок, а не исполнение моделью.
- F5: understood учитывает values и требуемые поля из отказа платформы.
- Предметный repository разрешён как источник readiness по №1241[41];
  onboarding-only флаги и постоянные mind-локаторы запрещены.
- Handle обязателен для общей завершённости, но напоминание только в UI;
  навыки не спрашивают его и не останавливаются на complete=false.
- Existing mind без собственной карты после settle: явное создание user=me
  после успешного поиска, затем перечтение; повтор whoami не является ремонтом.
- Оставшиеся handle-сопоставления в iskronify/standing/first-graph убраны.
- F6: reader/searcher сохраняют пины из принятого локального proxy-конфига.
  Ранее сохранённый CLI-прогон разрешил все семь проекций без модели.
  Это проверка данной машины, не обещание переносимости провайдера.

№1232[94] не заменяется нашим корпусным гейтом. #4696 уточнён отдельно.
