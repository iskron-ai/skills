# Виджеты окна Искрона

Виджет — огороженный блок кода с меткой `iskron`. Тело — ровно одна строка: имя виджета, следом в той же строке параметры `ключ=значение` через пробел, больше ничего. Окно рисует на месте блока живой вид данных графа; блок с другой меткой остаётся кодом.

- **Граф — всегда явно:** `realm=rN`, короткий id графа, тот же, что в ссылках «rN#N»; `realm=@owner/slug` — только если другой формы ты не видел. Граф не установлен — блок не ставь, скажи словами: без `realm` окно покажет плашку «укажите граф».
- **Данные виджет читает сам** в миг показа: не собирай список дел или агентов и не пересказывай его рядом. Что в деле затык и почему — пишется словами рядом с виджетом.
- **Канонические формы** — `case №N`, `node=#N`: окно терпит и `case N`, `node=N`, но пиши канон.
- **Незнакомое имя или параметр** — спокойная плашка, не ошибка; граф закрыт читающему — плашка «закрыто». Поверхность, не знающая договора (бот, чужой рендерер), показывает блок кодом — там виджет не ставь.

Пример блока:

```iskron
cases realm=rN status=open
```

## `cases` — живой список дел графа

**Когда:** человек спрашивает, какие дела идут, открыты или закрыты в графе или по узлу, — вместо того, чтобы пересказывать дела списком.

**Форма:** `cases realm=rN status=open node=#N`
- `realm` обязателен: короткий id графа (`rN`) или `@owner/slug`;
- `status` — `open` (по умолчанию), `closed` или `all`;
- `node` — только дела в охвате узла, включая вложенные; без него — весь граф.

Пример:

```iskron
cases realm=rN status=open
```

**Человек увидит:** заголовок со статусом и узлом, строки дел — «№N зачин» ссылкой на дело, статус, ведущий, время последней строки; дело, скрытое доступом, — номер без ссылки. Данные свежие на момент показа.

## `case` — карточка одного дела

**Когда:** речь идёт о конкретном деле, и человеку нужно видеть, где оно стоит, — вместо пересказа его состояния. Просто упомянуть дело в тексте — хватит ссылки «№N».

**Форма:** `case №N realm=rN`
- `№N` — номер дела в этом графе;
- `realm` обязателен: `rN` или `@owner/slug`.

Пример:

```iskron
case №26 realm=rN
```

**Человек увидит:** зачин дела ссылкой, статус, ведущий и время последней строки; нет дела или оно закрыто читающему — спокойная строка об этом.

## `agents` — активные агенты графа и их открытые дела

**Когда:** спрашивают, кто сейчас работает в графе, какие агенты активны, кто чем занят и в каких делах — вместо пересказа доски.

**Форма:** `agents realm=rN`
- `realm` обязателен: `rN` или `@owner/slug`.

Пример:

```iskron
agents realm=rN
```

**Человек увидит:** места на рабочих ролях (能) — адрес места, роль, живость, строка занятости и открытые дела каждого (дела читаются у первых шести мест). Места владельческих ролей (主) — человек и то, что говорит за него, — в список не входят. Доску мест видят те, кто может писать в граф; остальные видят «закрыто».
