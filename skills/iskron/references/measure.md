# Шаг 1 · Замер, до разбора запроса — дверь iskron

Шаг 1 двери **iskron**: исполняется при каждом вызове двери с запросом, до его разбора.

Два чтения графа плюс бесплатное локальное; замер вправе перебить любой маршрут.

1. **`iskron_orient(realm=..., focus=фокус-контур)`** из `AGENTS.md`: живые превращения и когда двигались, `НАТЯЖЕНИЯ` по классам, активные вопрошания, открытые дела контура (войти — ход из подсказки под ними).
2. **`iskron_orient(realm=..., focus=роль агента)`**, если она названа: число зовущих в заголовке очереди, риски, строка `КАНАЛ`. Список целиком — вызовом из хвоста выдачи, постранично; отвеченное от зовущего отличает печатная помета заката, не волевой модус. Очередь — фон: прочти зовущее, которого касается работа.

Бесплатно и первым — три признака выравнивания репозитория, в корне git (ближайший вверх каталог с `.git`): обложка — YAML-фронтматтер `AGENTS.md`; хук старта `iskronify` — запись `SessionStart` в `.claude/settings.json`, зовущая «Старт» двери `iskron`, или `.opencode/plugins/iskron-rituals.js`; штамп `iskronify` в `AGENTS.md`. Битый фронтматтер — не обложка; вне git-репозитория признаков нет, и первая строка таблицы не срабатывает. Хук старта требуется только от харнеса, которому `iskronify` его ставит: Claude Code — запись в `.claude/settings.json`, OpenCode — плагин ритуалов; Codex и pi его не получают, им хватает обложки и штампа. Затем `git status --short`, ветка, число в штампе. Живость тулов отдельно не проверяй. Ходы таблицы — починка, не замер.

Первое совпавшее перебивает запрос — скажи человеку, почему:

| Замер | Ход |
|---|---|
| в git-репозитории нет ни одного из трёх признаков | **onboarding** — ветвь «Первый граф» **iskronify**, в любом харнесе, звал ли хук старта или нет; при своих рабочих графах — сперва один вопрос: подключить репозиторий к одному из них или завести новый; тулов нет — сперва **establish-mcp** |
| признак есть, но недостаёт того, что `iskronify` пишет для твоего харнеса | выравнивание **iskronify** по шагу «Выравнивание», не онбординг |
| тулов нет или молчат | **establish-mcp**, затем исходный запрос |
| проектного графа нет: readiness и `iskron_realm(action="list")` устанавливают отсутствие собственных рабочих графов (личный mind не в счёт) | обеспечь личную память единым входом **minding**, «Личная принадлежность — до чтения и записи»: без хэндла, постоянного указателя и подмены отказа отсутствием. Работа в mind не пишется. Нуль рабочих графов — **onboarding**: в репозитории — ветвь «Первый граф» **iskronify**, вне репозитория — цикл onboarding; граф без вопроса не создаётся, графы, куда человека не звали, кандидатами не предлагай. Запрос — до первой записи по **writing**; места в новом графе ещё нет — ролей нет; первые записи (роль человека, контур, роль агента) ложатся без него, место — `iskron_stand`, как только роль агента легла |
| штамп ниже контракта `iskronify` (дата вместо числа — ниже любого) | прогони **iskronify** по правилу шага «Выравнивание» |
| ход будет писать в граф или говорить в деле | записи подписывает место этой сессии; знак — стояние названо привязанным к ней. Место держит среда и сказала это словом (промпт хода называет твоё место — у встроенного агента, у корня выровненного проекта в OpenCode, — или его назвал ответ `iskron_stand`) — оно твоё: для записи нового не занимай; нужен ли `take` для вахты или своего имени, говорит та же строка; не сказала — `iskron_stand` без `take`, вытеснение — только по шагу 3а **standing**. Не посажена — `iskron_stand`, как при пустом месте; после стопа владельца — только явный `iskron_stand` по его слову. **`iskron_channel(action="register", realm, karta=<роль>, name=<имя места>)` только называет место, которое эта сессия или её мост уже держит, — без такого места сервер его отказывает, назваться им нельзя; своего места нет → `iskron_stand` одним вызовом (**standing**).** Адрес согласования с человеком — seq роли владельца из `AGENTS.md`; `me` при нескольких ролях человека отказывает перечислением — бери seq оттуда |
| запись вернулась безавторной, хотя ты называешься | **standing**, «Дерево починки»: повторный `iskron_stand`, снова без автора — мост по **establish-mcp** (привязку держит только он) |
| граф назван голым slug | разреши через `iskron_realm(action="list")` до чтения |

Замер не перебил — иди в запрос. Ничего из замера не пропадает: его числа идут в ответ человеку.
