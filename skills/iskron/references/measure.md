# Шаг 1 · Замер, до разбора запроса — дверь iskron

Шаг двери **iskron**, вынесенный сюда дословно, чтобы дверь доходила до модели целиком в клиентах, режущих вывод тула (OpenCode: 51 200 байт). Исполняется при каждом вызове двери с запросом, до его разбора.

Два чтения графа плюс бесплатное локальное; замер вправе перебить любой маршрут.

1. **`iskron_orient(realm=..., focus=фокус-контур)`** из `AGENTS.md`: живые превращения и когда двигались, `НАТЯЖЕНИЯ` по классам, активные вопрошания, открытые дела контура (войти — ход из подсказки под ними).
2. **`iskron_orient(realm=..., focus=роль агента)`**, если она названа: число зовущих в заголовке очереди, риски, строка `КАНАЛ`. Список целиком — вызовом из хвоста выдачи, постранично; отвеченное от зовущего отличает печатная помета заката, не волевой модус. Очередь — фон: прочти зовущее, которого касается работа.

Бесплатно: `git status --short`, ветка, `AGENTS.md` и число в его штампе. Живость тулов отдельно не проверяй. Ходы таблицы — починка, не замер.

Первое совпавшее перебивает запрос — скажи человеку, почему:

| Замер | Ход |
|---|---|
| тулов нет или молчат | **establish-mcp**, затем исходный запрос |
| проектного графа нет: `iskron_realm(action="list")` пуст, несёт чужие графы или из своих (handle человека и его организации — `iskron_me(action="whoami")`) только `@handle/mind` | нет `@handle/mind` — заведи без вопросов граф и роль человека по **minding** (handle пуст — скажи и не заводи). Работа в mind не пишется: спроси одно — позвали ли человека в чей-то граф (да — пиши в названный); нет — проектный граф с именем из репозитория или просьбы, `iskron_realm(action="create")` (форму называют `list` и `action="?"`). Чужие графы кандидатами не предлагай. Запрос — до первой записи по **writing**; `register` не нужен — ролей в новом графе нет. Без `AGENTS.md` — прогони и **iskronify** |
| `AGENTS.md` нет или штамп ниже контракта `iskronify` | прогони **iskronify** по правилу шага «Выравнивание» |
| ход будет писать в граф или говорить в деле | назовись до первой записи: `iskron_channel(action="register", realm=..., karta=<роль>, name=<выведенное имя>)`; знак — стояние названо привязанным к этой сессии. Место держит среда и сказала это словом (промпт хода называет твоё место, как у встроенного агента, или его назвал ответ `iskron_stand`) — место уже твоё: нового не регистрируй. Такого слова нет — `register` как обычно. Места нет или его никто не держит → **standing**. Адрес согласования с человеком — seq роли владельца из `AGENTS.md`; `me` при нескольких ролях человека отказывает перечислением — бери seq оттуда |
| запись вернулась безавторной **повторно**, хотя ты называешься | **establish-mcp** — привязку держит только мост поставки |
| граф назван голым slug | разреши через `iskron_realm(action="list")` до чтения |

Замер не перебил — иди в запрос. Ничего из замера не пропадает: его числа идут в ответ человеку.
