# Развилки, на которых ошибаются — дверь iskron

Шаг 3 двери, вынесенный дословно, чтобы тело скилла доходило до модели целиком в клиентах, режущих вывод тула.

Признак-разделитель важнее списка фраз:

| Пара | Разделитель |
|---|---|
| **reconcile** ↔ **weaving** | reconcile — от кода внутрь графа, сверка следа после работы; weaving — неполнота внутри графа, снаружи ничего не сверяется |
| **reality-audit** ↔ **integrity** | reality-audit читает мир (прогнал, код выхода); integrity — граф (что затронет, есть ли рёбра). Состояние графа поведенческим доводом не бывает |
| **inquiry** ↔ **assembly** | inquiry — судьба каждого вопроса поштучно; assembly — над полем, группирует и зовёт inquiry, не наоборот |
| **writing** ↔ **design** | writing — о чём спорить уже не о чем; design — где выбор открыт. «Сделай, мы всё решили» — обычная работа |
| **writing** ↔ **minding** | личное знание человека — minding, даже о разработке; правило, инфраструктура и способ самого проекта — writing по полномочию |
| **writing** ↔ **intake** | своё различение или чужое слово с провенансом — артефакт вне графа прямо в просьбе |
| **assistant** ↔ **intake** | слово самого человека в дело — дословно; внешний текст, принесённый человеком или агентом, — сперва сверка с графом и делами |
| **intake** ↔ **feedback** | чужой текст о предмете работы — сверка и дельта в дело; опыт о методе — скилл, тул подвели — авторам инструмента |
| слышимость ↔ адресация в **standing** | «дошло / тишина / без автора» — стояние и его починка; «кому / что / от кого» — «Обмен» |
| **vahta** ↔ **chief-of-staff** | ярус ремесла не делает — разводит и фильтрует; vahta доводит свою работу до мержа. Речь о других агентах — ярус |
| **establish-mcp** ↔ **standing** | транспорт до графа против сокета канала — оба звучат «нет связи» |
| **feedback** ↔ жалоба на работу | feedback — об инструментах, которыми строил, не о результате |

«Мне удобнее сначала план» — личное (**minding**), даже о разработке; «в проекте план обязателен» — правило проекта по полномочию. Дом — по предмету, источнику, области, полномочию и аудитории, не папке или словам «я»/«всегда». Личное не отменяет обязательство; ситуативное не заменяет устойчивое молча. Файлы вне worktree поведение не настраивают. Маркеры — `references/phrasebook.md`; существенную неясность уточни одним вопросом.
