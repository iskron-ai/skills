# Переходы прежних контрактов — iskronify

Справка скилла **iskronify**: открой и прочти **до перемен в репо**, когда `contract` обложки ниже текущего, обложка прежней формы, штампа нет — либо когда признак прежней формы из списка ниже найден **содержимым** при любом числе, даже равном текущему. Переходы исполняются каждый в своём шаге дуги; в отчёте назови исходный контракт (или «обложки не было»). «С N» включает N: у файла с контрактом N исполни все переходы с N и выше; без контракта — все.

## Признаки прежних форм — ищи содержимым, не числом
- Строка AGENTS.md о стабе `MEMORY.md` или сам стаб-запрет над директорией памяти; отказ guard со словами «факты о коде → граф» или «стабе-запрете» → с 39.
- Свои хуки старта, пуша или мержа в `.claude/settings.json` / `settings.local.json`, свой плагин ритуалов `.opencode/plugins/*ritual*` → с 38.
- Плоские слоты во фронтматтере, раздел или таблица «Обложка», хвостовая строка `*(iskronify: контракт N, штамп …)*`, слот «Кросс-проектная память», анкета узлом `#N` → с 37.
- Нет `recaller.md` или `ingester.md` среди ролевых файлов; тело `weaver` с исключением впуска → с 36.
- Файл `searcher.md`; модель роли пином из референса → с 35.
- Свои ролевые файлы в индексе git → с 34.
- Нет `.worktrees/` в `.gitignore` → с 33.
- Нет `weaver.md` → с 28.
- Запись моста-спутника формой `sh -c` или с машинным путём; нет `designer.md` → с 18. Общая запись `iskron-sub` → с 17.
- Отказ guard — голый запрет без маршрута → с 24. Сторож незастывания на `Stop`, указатель момента writing на пишущих тулах → с 11.
- Таблица Reality внутри AGENTS.md → с 16.

## Переходы
- **С 39.** Стаб `MEMORY.md` не кладётся и не обещается (guard того же прогона его и не пропустил бы): строка персистентности говорит, что директорию держит memory-guard; найденный свой стаб оставь как есть. Отказ guard — текстом `prepare` (Шаг 4): свойства кода → AGENTS.md, смысл кода → граф. Файл с контрактом **выше** поставки не понижается — обновляется поставка (шапка скилла).
- **С 38.** Сними свои ритуалы старта, пуша, мержа и свой плагин ритуалов — Шаг 4, «Переход»; ветки иных родов целы.
- **С 37.** Обложка — блок `iskron:`; слоты-суждения — раздел «Проект». Прежняя обложка (плоские слоты во фронтматтере, раздел или таблица «Обложка», хвостовая строка штампа; мост её не переносит — пункт `left`): граф — rN в `graph`, фокус-контур и роль агента — числами в `holon` и `agent_role`, флагами `prepare` (`--graph`, `--holon`, `--agent-role`); Nature, Цена поломки, Потребители, Стек, Гейт, Раскладка, Фидбэк-рефлексия, Interop — значениями в «Проект»; `Репозиторий`, `Роль владельца`, `Reality`, `Согласование`, ключи ` — источник` и строку штампа сними. «Не согласовано — дело №N» — «открыто», вопрос остаётся в деле; «согласовано: кто» — в git и деле, не в файле. Дырка или «Согласование», называющие узел-анкету (`#N`), — прочти узел (`iskron_look`): ответы — в слоты, открытые — словом в деле выравнивания; узел отпусти (`visarjana`, reasoning «перенесён в дело №N»), чужой — слово автору. Слот «Кросс-проектная память» сними (Шаг 1).
- **С 36.** `recaller` и `ingester` в обе платформы и в `.gitignore`; тело `weaver` — без исключения впуска (Шаг 6).
- **С 35.** Сними свой `searcher` (оба файла); модели — рекомендация класса, выбор человека из mind.
- **С 34.** Свои ролевые файлы — из индекса (`git rm --cached`) и в `.gitignore` по именам; файлы остаются, чужие не трогай; хвост репо — разделом AGENTS.md (Шаг 5, Шаг 6).
- **С 33.** `.worktrees/` в `.gitignore`; уборка брошенных деревьев и кэшей — «Дисциплина веток» скелета.
- **С 28.** Допиши `weaver` по текущему блоку; свою прежнюю проекцию этой роли сверь с ним.
- **С 24.** Отказ guard — маршрутом текста `prepare`, не голым запретом (Шаг 4).
- **С 18.** Запись моста-спутника — блоком `node -e` из `delegation-1.md` («Форма записи одна на все ОС») вместо `sh -c` и абсолютного пути; допиши `designer`.
- **С 17.** Общая запись `iskron-sub` — своей `iskron-sub-<роль>` в каждом ролевом файле Claude Code.
- **С 16.** Таблица Reality из AGENTS.md — в `REALITY.md` строками целиком, датированные наблюдения из неё — узлами в граф (не удаляются); в AGENTS.md остаётся указатель.
- **С 11.** Хуки контракта 10 — сторож незастывания на `Stop`, указатель момента writing — сними свои, чужие не трогай.

Подъём счётчика зовёт репозиторий на прогон, не свидетельствуя перевыравнивания.
