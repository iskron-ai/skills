# Шаг 6 — Ролевые суб-агенты делегирования — iskronify

Шаг процедуры скилла **iskronify**, вынесенный сюда дословно, чтобы скилл доходил до модели целиком в клиентах, режущих вывод тула (OpenCode: 51 200 байт). Исполняется в своём месте процедуры, после Шага 5.

Доктрина и шаблоны файлов — `references/delegation.md`; прозой AGENTS.md не проецируется.
- Claude Code, всегда: `.claude/agents/reader.md` и `searcher.md` (средний тир), `worker.md`, `designer.md`, `reviewer.md` и `verifier.md` (верхний: исполнение, суждение, ревью и приёмка) — алиасы `sonnet`/`opus`; `haiku` — ни одной роли. `verifier` и `reviewer` — даже без рантайма: они делают `REALITY.md` и ритуал ревью исполнимыми; `searcher` — только чтение, поиск кандидатов «что граф знает о X» вне окна сессии: находки — зацепки, позвавший принимает их сверкой с окрестностью. Ни одна роль в граф не пишет; ткачество ведёт сам ведущий.
- OpenCode (`opencode.json` / `.opencode/` или слово пользователя): `.opencode/agents/` те же шесть, `mode: subagent`, модель **пришпилена** в каждом файле из настройки пользователя (спроси или прочти `opencode.json`); из референса id не копируй; верхний тир — только Claude Opus или GPT-6.1 Sol.
- **Запись моста-спутника — одна форма на все ОС** (`delegation.md`, «Форма записи одна на все ОС»): `command: node`, `args` — `-e` с кодом, собирающим путь к домашнему мосту из `os.homedir()`, затем `--` и `--satellite`; копируй блок из референса дословно. Проверена живьём на macOS (Claude Code 2.1.285); на Windows не сверена. Машинного пути в файле нет — он коммитится как есть. Прежняя проекция (`sh -c`, контракт до 18; абсолютный путь) — перепиши этим блоком.
- `description` — канал маршрутизации: триггер-образно — когда звать, что вернётся, чему не доверять.
- Объёмное суждение без записи в граф (проекция файлов прогона `iskronify`, разбор слотов против кода) идёт роли `designer`; проектирование в графе, запись, ткачество, решения владельца и диалог остаются ведущему; приёмное (ревью диффа, приёмка утверждения) идёт холодному — ролевой файл законен; поиск по вопросу, только чтение, — тоже.
- **Мержи**: одноимённый агент другого набора — вложи своё или переименуй свой (`iskron-reader`). Своя прежняя проекция (тело прошлого контракта) — перепиши текущим телом; хвост репо (`delegation.md`, «Хвост репо») — перенеси как есть; чужое тело — не трогай.
- Self-check: файлы парсятся; каждый файл Claude Code несёт свою запись моста-спутника `iskron-sub-<роль>` — общей записи `iskron-sub` (контракт до 17) ни в одном нет; форма записи — `node -e` из референса, `sh -c` и машинного пути нет ни в одном; `doctor` из корня репо показывает файлы проекта в разделе «субагенты» без строк `НАДО:` (на английской поверхности — `TODO:`; есть — исполни их до отчёта); тела `worker`, `verifier`, `reviewer`, `designer` несут вход в дело строкой запуска и на общем мосту не зовут `iskron_stand`, `join`, `leave` (`reader` и `searcher` в дело не пишут); ни одно тело не разрешает запись в граф; файлов `searcher` и `designer` нет или `reader` пришпилен к `haiku` (контракт до 18) — допиши и перепиши; `worker` пришпилен к `sonnet` (контракт до 23) — перепиши на `opus`; своя прежняя проекция `weaver` (контракт до 22) — удали; `verifier` и `reviewer` читают `REALITY.md` репо; пришпиленные модели существуют; AGENTS.md не несёт доктрины делегирования (максимум указатель); хвост репо не потерян — по диффу каждого ролевого файла строки под `## Этот репо` и ключи фронтматтера сверх блока те же до и после прогона; у прежней проекции без заголовка каждая снятая строка, называющая предмет репо, стоит в хвосте, а снятые родовые названы в отчёте; чужие файлы не перезаписаны, свои прежние не оставлены.
- Роль, спроецированная прогоном, в той же сессии может не зваться по имени (каталог ролей читается на старте) — скажи это в отчёте; холодное ревью этого прогона тогда идёт общим суб-агентом с телом роли в брифе, модель — только верхнего тира (Claude Opus или GPT-6.1 Sol): параметром вызова, где харнесс его даёт; где не даёт — моделью сессии, только если она из них, и отчёт это говорит; иначе ревью этим ходом не идёт — отчёт говорит и это.
