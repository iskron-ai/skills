# Шаг 5 — Гигиена репозитория — iskronify

Шаг процедуры скилла **iskronify**: исполняется в своём месте, после Шага 4.

- Закоммить `.claude/settings.json`, внеси в `.gitignore` `.claude/settings.local.json`, `.worktrees/` (рабочие деревья веток), свои ролевые файлы по именам в `.claude/agents/` и `.opencode/agents/` (модель человека — проекция на машине, Шаг 6; чужие агенты в каталогах не трогай); широкий игнор `.claude/` — добавь `!.claude/settings.json`. Свои ролевые файлы уже в индексе — `git rm --cached` по тем же именам: файлы остаются только в этом дереве — в других копиях и деревьях подтяжка коммита их сотрёт, там роли до вызова по имени возвращает выравнивание старта (Шаг 6); скажи это держателям других копий словом в деле прогона. Проверь `git check-ignore -v .claude/settings.json .claude/settings.local.json .worktrees/x .claude/agents/reviewer.md .opencode/agents/reviewer.md` и что `git ls-files` не называет ни одного из своих шести.
- **Трекаемые secret/env**: `git ls-files '.env*' '*secret*' '*local*'`; трекается реальный (не `.example`) — в «Конвенции кода»: локальные правки не стейджить (`git update-index --skip-worktree <file>`), никогда `git add -A` / `commit -a`.
- Директория проектной памяти (`~/.claude/projects/<encoded-path>/memory/`): **эвакуируй, затем заморозь**. Решения и ограничения → граф; ритуалы → AGENTS.md; ловушки → дом по «Раскладке»; состояние ветки → git и PR; серверы и датированные долги → граф проекта; собственное пользователя → его личный граф (**minding**); предпочтения — по Шагу 1. Затем `MEMORY.md` — однострочный стаб-запрет («состояние живёт в репо или графе — см. AGENTS.md, раздел <заголовок раздела о персистентности, как он стоит в файле>»), memory-guard блокирует дальше. Стаб поверх непрочитанного уничтожает то, что должен был переселить.
- **Форжа и CLI — выведи, не предполагай GitHub**: `git remote -v` → `gh` (GitHub), `fj` (Forgejo/Codeberg), `glab` (GitLab), `tea` (Gitea); проверь установку и вход, назови в «Git-воркфлоу» с командой наблюдения. Неопознанный хост — спроси.
- «Стек», «Команды», «Структура проекта», «Конвенции кода» — реальное содержимое по зрелости; пусто в первый день — нормально, `TBD` — нет.
- **`HANDOVER.md` не заводится**, и AGENTS.md говорит почему (раздел скелета). Файл есть — эвакуируй по домам (git, PR с номером дела, дело, модусы узлов) и удали.
- `README.md` корня — короткий, человеку, AGENTS.md не дублирует. README компонента по «Раскладке» — карта кода делателя, компактно; прогон их не пишет.
