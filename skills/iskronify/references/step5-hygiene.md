# Шаг 5 — Гигиена репозитория — iskronify

Шаг процедуры скилла **iskronify**, вынесенный сюда дословно, чтобы скилл доходил до модели целиком в клиентах, режущих вывод тула (OpenCode: 51 200 байт). Исполняется в своём месте процедуры, после Шага 4.

- Закоммить `.claude/settings.json`, заигнорь `.claude/settings.local.json`; широкий игнор `.claude/` — добавь `!.claude/settings.json`. Проверь `git check-ignore -v .claude/settings.json .claude/settings.local.json`.
- **Трекаемые secret/env**: `git ls-files '.env*' '*secret*' '*local*'`; трекается реальный (не `.example`) — в «Конвенции кода»: локальные правки не стейджить (`git update-index --skip-worktree <file>`), никогда `git add -A` / `commit -a`.
- Директория проектной памяти (`~/.claude/projects/<encoded-path>/memory/`): **эвакуируй, затем заморозь**. Решения и ограничения → граф; ритуалы → AGENTS.md; готчи → дом по «Раскладке»; состояние ветки → git и PR; серверы и датированные долги → граф проекта; собственное пользователя → его личный граф (**minding**); предпочтения — по Шагу 1. Затем `MEMORY.md` — однострочный стаб-запрет («состояние живёт в репо или графе — см. AGENTS.md, раздел <заголовок раздела о персистентности, как он стоит в файле>»), memory-guard блокирует дальше. Стаб поверх непрочитанного уничтожает то, что должен был переселить.
- **Форжа и CLI — выведи, не предполагай GitHub**: `git remote -v` → `gh` (GitHub), `fj` (Forgejo/Codeberg), `glab` (GitLab), `tea` (Gitea); проверь установку и вход, назови в «Git-воркфлоу» с командой наблюдения. Неопознанный хост — спроси.
- «Стек», «Команды», «Структура проекта», «Конвенции кода» — реальное содержимое по зрелости; пусто в первый день — нормально, `TBD` — нет.
- **`HANDOVER.md` не заводится**, и AGENTS.md говорит почему (раздел скелета). Файл есть — эвакуируй по домам (git, PR с номером дела, дело, модусы узлов) и удали.
- `README.md` корня — короткий, человеку, AGENTS.md не дублирует. README компонента по «Раскладке» — карта кода делателя, компактно; прогон их не пишет.
