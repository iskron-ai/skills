# js/extension — расширение pi

Один выход `extensions/iskron.js`, собираемый из `main.ts`. Тулы и канал независимы; транспорт и удержание места остаются в мосту.

- `main.ts` — регистрация половин расширения и сообщений об их отказах.
- `tools.ts` — процесс моста, MCP-тулы и передача уведомлений каналу.
- `channel.ts` — доставка в pi: адресованные слова и ответы сохраняют свой путь; мягкие вопросы графа ждут `before_agent_start`, возвращаются одним служебным сообщением и не вызывают `sendMessage`/`triggerTurn` (#7334 → #7333). Стоп и завершение сессии удаляют ожидающее.
- `pulse.ts` — линия живости сессии; `usage.ts` — расход; `home-copy.ts` — домашняя копия поставки.

Распознавание вопросов, свёртка и память событий общие с мостом/OpenCode: `../shared/graph-inbox.ts`, `seen.ts`, `softbatch.ts`. Пробы — `../tests/extension.test.mjs`; наводка на прежнюю сборку — `ISKRON_EXTENSION`.
