# js/cli — подкоманды одного исполняемого файла поставки

Вход — `main.ts` (сборка: `skills/establish-mcp/scripts/iskron.mjs`, дом — `~/.iskron-bridge/iskron-bridge.mjs`); список подкоманд — `node iskron.mjs --help`.

- `doctor.ts`, `doctornode.ts`, `doctorpaths.ts`, `doctorskills.ts`, `codexcache.ts`, `opencode-config.ts`, `subagents.ts`, `subwords.ts`, `satform.ts`, `satprobe.ts`, `frontmatter.ts`, `installnames.ts` — `doctor`: какая сборка стоит и работает ли она.
- Слова подкоманд — в слое поставки (`js/delivery/words/`: `cli.ts`, `doctor.ts`, `doctorharness.ts`, `subagents.ts`, `satprobe.ts`, `rituals.ts`); ядро берёт их через `words()` (граф @nks/nks-dev, узел #6806).
- `update.ts` — `update`: свежий релиз в дом.
- `orchestra.ts` — `orchestra <on|off|status|step> [--realm <граф>]…`: дверь оркестратора демона — флаг и граница рядом с грантом, один такт чтения очередей от курсора; `on` требует согласия машины (`ISKRON_ORCHESTRA=1`). Слова — `js/delivery/words/orchestra.ts`, помощь — `cli.ts`; пробы — `js/tests/orchestra.test.mjs` (граф @nks/nks-dev, #7514/#8202).
- `use.ts` — `use`: постоянный выбор адреса сервера.
- `prepare.ts` (аргументы, ответ, код выхода), `preparefiles.ts` (обложка через `../shared/coverwrite.ts`, поле `rituals:` не трогает, незнакомый ритуал — модели, `cover.rituals`; заготовки `REALITY.md`, указатель `CLAUDE.md`, адрес из `origin`), `preparehooks.ts` (memory-guard в `.claude/settings.json` рядом с чужими; свои хуки старта, пуша и мержа репо называет модели на снятие — их несёт поставка), `hookkinds.ts` (какие ритуальные хуки держит сам репо), `preparegraph.ts` (контур и роль по `origin`: атрибут `repository` контура, стюард контура — грант моста, без сети молча), `preparescripts.ts` (хук, вынесенный в скрипт, узнаётся по тексту скрипта; не узнан — своего не пишет и называет стоящий модели, #9331) — `prepare [--dir] [--graph rN] [--holon N] [--agent-role N] [--contract N] [--stamp] [--case N] [--json]`: подготовка репо одним вызовом без модели и сети; стоящее не перезаписывается, повтор ничего не меняет; ключ обложки, названный дважды, оставляет `AGENTS.md` нетронутым и уходит модели (`cover.repeat`); код 0 — всё стоит, 3 — осталось модели (`left`), 1 — отказ без записи, 2 — форма аргумента (граф @nks/nks-dev, узлы #9319, #9316). Слова — `js/delivery/words/prepare.ts`; пробы — `js/tests/prepare.test.mjs`, `js/tests/prepare-scripts.test.mjs` (guard держится байт в байт с образцом `skills/iskronify/references/hooks.md`).
- `status.ts`, `statusdisk.ts` — `status [--json]`: снимок сессий, их установленного набора скиллов и мест демона без открытия сессии; отдельно мосты мимо демона и записи диска без живого держателя. Слова — `js/delivery/words/machinestatus.ts`.
- `stop.ts` — `stop <место|id сессии> [--realm]`: человек снимает место агента машины — место (полный адрес `@handle:name` сверяется с адресом места в снимке; чужой владелец — отказ), его id, сервер и api сессии из снимка демона (api старого демона — из записи держания), ключ сервера места — личный токен, если его дом (переменная адреса или файл `server`) называет сервер места, иначе грант сервера места, освежённый как у моста, не освежился — «войди заново» (`stopapi.ts`); приказ останова (POST /standings/{id}/stop), на api без ручки (404) — снятие места (DELETE /standings/{id}) (граф @nks/nks-dev, узлы #7518, #5085). Слова — `js/delivery/words/stopcli.ts`; проба — `js/tests/stop-cli.test.mjs`.
- `onboard-hook.ts` — не подкоманда, а свой малый вход (сборка: `hooks/onboard.mjs`, хук `SessionStart` плагина Claude Code в `hooks/hooks.json`, записи `startup` и `compact` с одной командой; команда — `node -e` с импортом, отказ которого глушится: до выпуска, впервые пишущего файл, хук молчит): каталог сессии из входа хука (`cwd`), иначе `CLAUDE_PROJECT_DIR`, иначе свой; `source` входа `compact` — одна строка `COMPACTION` в stdout (`back` с ролью и местом, если записи держания называют ровно одно место Claude Code для каталога, `../shared/seatbydir.ts`; иначе `bare`), пробы — `js/tests/compact-hook.test.mjs`; иначе ни одного признака выравнивания репозитория (`../shared/reposigns.ts`) — одна строка `ONBOARD_START`, иначе ничего; код выхода всегда 0. Мостом не сделан нарочно: старт сессии ждёт хук, а старый мост неизвестную подкоманду принял бы за запуск моста. Пробы — `js/tests/reposigns.test.mjs`.
- `rituals-hook.ts` — второй малый вход (сборка: `hooks/rituals.mjs`, впервые выйдет с выпуском из `PENDING` `js/build.mjs`): ритуалы плагина Claude Code по обложке репо (`../shared/ritualcover.ts`) — `SessionStart` (кроме `compact`) — слово старта `PREPARE` или раннего входа `RITES`, пока обложка называет только граф, `PostToolUse`/`Bash` — слова пуша и мержа `RITES` по исходу (`../shared/ritualjudge.ts`), `Stop` — слово конца хода `TURN` (`../shared/turnend.ts`, #9342): `turnread.ts` читает последний ход транскрипта — начат уведомлением задачи сторожа (Monitor или фоновая оболочка с `watchdog`, кроме `hello` и истечения), без слова человека, кончился текстом без ask/say/answer/talk и send — `decision: block` с этим словом, при `stop_hook_active` молчит; обложки нет — тоже (кадр доказывает место); вид, который репо держит своим хуком (`hookkinds.ts`) или не включает поле `rituals:` обложки, молчит; memory-guard остаётся хуком репо. Пробы — `js/tests/rituals-delivery.test.mjs`, `js/tests/rituals-optout.test.mjs`, `js/tests/rituals-turn.test.mjs` (граф @nks/nks-dev, #9319, раздел РИТУАЛЫ).
- `rituals.ts` (слова и исход), `ritualprobe.ts` (подставной ctx OpenCode с двумя каталогами), `ritualcalls.ts` (вызовы тулов для хуков) — `check-rituals`: подписка плагинов ритуалов `.opencode/plugins/*` на поток событий не пишет в сессии чужих каталогов, хуки тулов не ломаются в своей (граф @nks/nks-dev, узлы #6686, #5048). Пробы — `js/tests/ritual-scope.test.mjs`; `scripts/check-ritual-scope.mjs` зовёт ту же подкоманду из dev-сборки.
