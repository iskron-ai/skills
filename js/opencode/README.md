# js/opencode — плагин iskron для OpenCode 2: тулы через мост, канал, команды

Один плагин, три половины; у каждой корневой сессии свой мост, а значит своё стояние (граф @nks/nks-dev, узел #4266). Выход — `skills/establish-mcp/scripts/opencode-plugin.js`, ставится копией в `~/.config/opencode/plugins/iskron.js`.

- `plugin.ts` — дверь: половины, поток событий сервиса, хуки сессии.
- `onboardstart.ts` — первый промпт корня: признаки репозитория каталога сессии (`../shared/reposigns.ts`, харнесс `opencode`); ни одного из трёх — одна строка `ONBOARD_START`, иначе и вне git-репозитория — тишина. Только локальное чтение: ни вызова графа, ни моста, ни места. Один раз на читаемую корневую сессию; ребёнок, нечитаемая сессия и стоп молчат. Порядок слов посадка → приглашение. Пробы — `onboarding start` в `opencode.test.mjs`, совместный старт в `onboardstart.test.mjs`; serve — `scripts/rootseat-run-opencode.mjs --onboarding=fresh|partial|outside` (без платной модели).
- `service.ts` — вызов через слот держит его занятым и освежает простой.
- Половина «тулы»: `tools.ts` — мост на сессию; `half.ts` — её вход для `plugin.ts` и пустая форма; `slot.ts` — мост одной сессии; `bridge-io.ts` — поиск моста, кэш тулов, рукопожатие; `host.ts` — что OpenCode говорит о себе; `login.ts`, `devicewait.ts` — вход человека; `status.ts` — текст `iskron_bridge`; `skillread.ts` — чтение файлов скиллов поставки вне рабочей копии.
- Слух и места: `keep.ts` — слух переживает простой, перезапуск и вытеснение; `keepalive.ts` — место держит каталог загруженным; `marker.ts`, `records.ts`, `adopt.ts`, `procstart.ts` — маркер потери и возврат мест; `moves.ts`, `handoff.ts` — перенос сессии между папками; `twins.ts` — экземпляры на два написания одного каталога; `rootseat.ts` — корень выровненного проекта пытается встать по обложке `AGENTS.md` (`../shared/cover.ts`) до первого модельного запроса: своё место с диска, иначе служебный stand на роль; первый промпт ждёт не дольше срока и сообщает действительное удержание или отказ, поздний исход входит вторым словом через канал, повисшая посадка отпускает очередь по потолку; `rootseat-by.ts` — stand и строгое сличение с обложкой (несличённый rN не отменяет факта удержания); `rootseat-tools.ts` — срок жизни попытки и доказательство из ответа моста. Нет обложки или каталога сессии — ни посадки, ни слова.
- Дочерние сессии: `satellite.ts` — спутник места корня; `children.ts` — мосты детей и возврат ведущего; `leads.ts`, `leaddoors.ts`, `leadwords.ts` — ведущий субагент (договор и двери к OpenCode, доступ к словам слоя); `casesleft.ts` — последнее ли дело покинул ведущий: слово платформы (`iskron_case` mine мостом ребёнка), не свой учёт (#7234); `release.ts` — revoke запустившего: после конца ребёнка снятие места на платформе мостом запустившего (#7505); `leadends.ts` — кончившиеся ведущие: реестр процесса на globalThis и запись на диске (`opencode-ended.*`), их видят все экземпляры и следующий после перезагрузки, снимает новое явное занятие места (#7505, #4266); `leadframes.ts` — кадры ведущего: кончившемуся ничего, слово запустившего (непосредственного родителя-сессии и его места) — в идущий ход; `launch.ts` — строка запуска с делом; `runends.ts` — кончившиеся дети; `cascade.ts` — отмена хода родителя; `notice.ts` — родное уведомление о субагенте; `waits.ts` — ребёнок, которого родитель не слышит, — только ребёнок, которого держит этот экземпляр (#6815 п.7).
- Слова плагина — в слое поставки (`js/delivery/words/opencode.ts`, `opencode-keep.ts`, `leads.ts`, `plugin.ts`), на языке сессии (`shared/lang.ts`); ядро текстов и имени продукта не несёт (#6806).
- Половина «канал»: `channel.ts` — кадры стояния в сессию промптом, пачки дела; `tacts.ts` — такт внимания ждёт конца занятого хода последним (#6569); `lifecheck.ts` — побудка о живости: отдельным промптом в очередь корня, текст платформы и строка хода ответа; место дочерней сессии ребёнка не будит — корню строка о нём с вызовом revoke (дело №1046); `cuts.ts` — прерывание хода остановленной сессии с повторами и его исход, который мост ждёт для ответа на приказ останова (`iskron/halted`); `cutwait.ts` — исходы прерываний и родословные экземпляров в реестре процесса: подтверждение ждёт сессию и всех её потомков, кто бы их ни прерывал, и перечитывает их, пока набор не устоится (#7510); потолок подтверждения и остановка экземпляра снимают его ожидания из реестра; `halts.ts` — остановленная снятием места сессия и все её потомки (по цепочке родителей) не получают слов канала до явного занятия места, их ходы прерваны (#7439, #7440); остановка лежит на диске рядом с маркерами (`opencode-stopped.*`) вместе со словом стопа для контекста её ходов (#7585) — её читают все экземпляры и следующий после перезагрузки, места-спутники потомков снимает экземпляр, где они стоят.
- `commands.ts` — скиллы поставки в палитре «/»; `usage.ts` — расход сессии в attrs места; `models.ts` — модель сессии от харнесса для места-спутника (#7591); `pulse.ts` — слово сессии о ходе мосту для кадра живости места, `inbox.ts` — какие inbox-элементы сессии он ждёт для read_at.

Пробы — `js/tests/opencode.test.mjs` (`make test-opencode`), наводка на старую сборку — `ISKRON_OPENCODE_PLUGIN`.

Автопосадка подчиняется стопу владельца (`halts.ts`, в том числе записи на диске и стопу предка): ни stand, ни слова посадки; слово стопа даёт context-хук. `forget` и выгрузка отменяют очередь и подавляют позднее слово. `rootseat-tools.ts` держит срок жизни её моста: уже отправленный connect не обрывается, после ответа место снимается штатным `channel revoke`, затем мост закрывается. Отказ/таймаут снятия — явная ошибка; при недостижимом сервере место может дожить до серверного простоя. Остановленный экземпляр и удалённая сессия не создают новых слотов. Служебный held не снимает стоп. Пробы: `rootseat-safety.test.mjs` и P1/P2 в `rootseat.test.mjs`.

Предварительность для слова — только положительный признак `provisional` от обслуживающего моста: `held`, структурированный ответ stand или resume/check. Запись на диске не доказывает, что старый демон понимает правило замены. Нет признака — слово своего места с take. Реальное написание графа при отсутствии held.place читается из записи той же сессии/ключа; нет записи — граф неизвестен, санированный ключ графом не становится. При несовпадении с обложкой или несличённом rN слово всё равно называет удерживаемое место, роль/граф и take либо revoke, не говорит «не посажена». Сличение — точный полный адрес либо полный slug-компонент, без суффиксов внутри имени. Неизвестный каталог сессии не подменяется домом экземпляра: посадки нет. Пробы — `rootseat-review.test.mjs`; смешанный живой прогон — `ISKRON_BRIDGE_PATH=<старый мост без признака> node scripts/rootseat-run-opencode.mjs --legacy-bridge --keep`.

Автопосадка начинается только из первого prompt-хука, не из `session.created`. `ISKRON_ROOT_SEAT=0` отключает её для служебного headless run; окружение должно дойти до процесса сервера (для `opencode run` — с `--standalone`). Происхождение отдельного корня без parentID надёжно не определяется, по TTY/имени/модели оно не угадывается. После свежего успешного stand разрешённый мостом граф — из его ответа; вернувшееся с диска место само по себе соответствия rN/слага не доказывает. Пробы — `rootseat.test.mjs`, `cover.test.mjs`; настоящий serve с локальным сценарным провайдером — `scripts/rootseat-run-opencode.mjs`.
