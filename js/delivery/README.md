# js/delivery — слой поставки моста

Здесь живёт то, чем поставка iskron отличается от соседней: версия и метка канала сборки, а частями переноса — имя продукта и выводимое из него, адреса по умолчанию, тексты, языки (граф @nks/nks-dev, узлы #6806, #6809). Всё прочее в `js/{bridge,shared,opencode,extension,watchdog,cli}` — ядро, которое соседняя поставка копирует файлами.

- Ядро импортирует слой одним путём — `../delivery/index.ts`; alias и define сборки нет, копии различаются содержимым этого каталога. Набор экспортов `index.ts` и есть контракт: недостающий экспорт — ошибка `make typecheck` в ядре.
- `version.ts` — `VERSION` (штампует release-please, `release-please-config.json`) и `CHANNEL_MARK` (`js/build.mjs` читает её отсюда и в сборке выпуска заменяет `:dev` на `:release`).
- Слой не импортирует исполняемое ядро; зависимость от типов ядра — `import type`.
