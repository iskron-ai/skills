# js/dsh — слух dsh-сессии: кадры стояния ходами живой сессии

Кордис-плагин для DeepSeek Harness (граф @nks/nks-dev, узел #10776). Своих моста и тулов нет: стояние держит мост машины, а плагин прицепляется локальным клиентом к сокету стояния тем же путём, что сторожа (`js/watchdog/client.ts`).

- `plugin.ts` — вход бандла, `apply(ctx)`: `agent/created` — взять агента и встать слухом; `session/disposed` — отцепиться, ничего не слать; `session/event` типа `compaction/end` — слово о роли после сжатия.
- `seat.ts` — выбор стояния (раздел «Как выбирается стояние» ниже).
- `hearing.ts` — прицепление и доставка: каждый адресованный месту кадр — одно сообщение `next-turn`, текст кадра — общим кодом `js/shared/frame-text.ts`; отметка доставленного — `noteSeen` после отправки.
- `compaction.ts` — слово возврата роли по образцу `js/opencode/compaction.ts`: место из hold-записи, без записи — голое слово (словарь `COMPACTION`).

## Как выбирается стояние

Как у сторожа без аргумента (`resolveStanding`), с его собственной развилкой на случай нескольких:

1. единственный ключ в `standings/*.key` каталога authDir (`ISKRON_BRIDGE_AUTH_DIR`, иначе дом моста) — он;
2. несколько — живая (не протухшая, не `left`) hold-запись `*.hold` с `cwd`, равным `process.cwd()` (через `sameDir`), называет стояние этой сессии; ровно одна — она;
3. ничего или неоднозначно — глухо: одна громкая строка в консоль dsh (`DSH`-словарь), без прицепления.

Окно прицепления и повторы — окно самого `attach` (60 с, шов `ISKRON_WATCHDOG_ATTACH_MS`): стояние появляется, когда сессия займёт место, уже после `agent/created`.

Слова — `js/delivery/words/dsh.ts`; источник сообщений — `CLIENTS.dsh`. Граница ядра: `make check-core` держит каталог чистым (без кириллицы и имени продукта).
