# js/dsh — слух dsh-сессии: кадры стояния ходами живой сессии

Кордис-плагин для DeepSeek Harness (граф @nks/nks-dev, узел #10776). Своих моста и тулов нет: стояние держит мост машины, а плагин прицепляется локальным клиентом к сокету стояния тем же путём, что сторожа (`js/watchdog/client.ts`).

- `plugin.ts` — вход бандла, `apply(ctx)`: `agent/created` — взять агента и встать слухом; `session/disposed` — отцепиться, ничего не слать; `session/event` типа `compaction/end` — слово о роли после сжатия, все события сессии корня — конец хода (`turnend.ts`); `tools/post-execute` — строки пуша и мержа (`rites.ts`).
- `start.ts` — слово старта (#10921): на первом `agent/created` сессии (`source` `startup`/`resume`; позднейшие агенты сессии — субагенты; после `session/disposed` первым снова считается следующий) обложка репо каталога сессии читается общим `js/shared/ritualcover.ts`, как в ритуалах OpenCode, и слово (`PREPARE.start` + хвост `DSH`: слушаю место / место снято с прошлым процессом) ложится секцией `delivery:start` в `payload.agent.ctx.systemPrompt` — агент-локально, снимается с агентом; наблюдено на 0.2.2-rc.1: секция доходит в `system` каждого запроса модели, на resume тоже. Нет обложки, чужая, ритуал `start` выключен — тишина. Контракт обложки ниже поддерживаемого (`js/shared/covercontract.ts`) — предупреждение первым в той же секции, ритуал `start` включён или нет, как в OpenCode и Claude Code (#11071). Репо без единого признака выравнивания (`js/shared/reposigns.ts`, харнесс `dsh` — хука старта ему не пишут, как `null`) — после слова старта строка приглашения `ONBOARD_START` в той же секции, как `onboardstart.ts` OpenCode и `onboard-hook.ts` Claude Code; вне git-репозитория и в чужой обложке — тишина. Предел: в долгоживущем процессе (`dsh web`) каждая сессия получает слово своим первым агентом — пробой на подставном ctx, живьём web не проверен.
- `root.ts` — корневой агент сессии (#11071): тул `subagent` dsh порождает агента в том же процессе, и `agent/created` приходит и для него (наблюдено живьём на LAB, 0.2.2-rc.1). Слух, слово старта и ритуалы держит корневой: субагент — сессия которого называет родителя (`header.parentSession`, `origin: "subagent"`, `delegationDepth` > 0 — по типам установленного `@deepseek-ai/dsh-session` 0.2.2-rc.1, форма payload субагента не наблюдена), а без такого заголовка — свежий (`startup`/`resume`) агент при живом корне — их не перехватывает; `clear`/`compact` заменяют агента корня. `session/disposed` и `session/event` чужой сессии (субагента) корень не трогают.
- `seat.ts` — выбор стояния (раздел «Как выбирается стояние» ниже).
- `hearing.ts` — прицепление и доставка: каждый адресованный месту кадр — одно сообщение `next-turn`, текст кадра — общим кодом `js/shared/frame-text.ts`; отметка доставленного — `noteSeen` после отправки.
- `rites.ts` — строки пуша и мержа (#11071): на `tools/post-execute` (водопад `(exec, result, next)` — решение `next()` проходит неизменным) вызов тула `bash` судится общим `js/shared/ritenotes.ts` — тем же составом строк, что ритуалы OpenCode и хук Claude Code, по исходу `js/shared/ritualjudge.ts` (видимый отказ гасит, тихий пуш — по состоянию git каталога сессии, пуш одних меток молчит; пуш в ствол — слово мержа); строки идут в живую сессию одним сообщением `next-turn` после цикла публикации. Форма вызова (`exec.name`, `exec.arguments.command`, `result.value` с `exitCode`, `stdout.text`, `stderr.text`) взята из типов и кода установленного `@deepseek-ai/dsh` 0.2.2-rc.1, живьём не наблюдена.
- `turnend.ts` — конец хода на вахте (`js/shared/turnend.ts`, #9342, #9345, #11071) по образцу `js/opencode/turnend.ts`: кадр, вложенный слухом (по id или тексту сообщения; счёт без адресованного месту — не кадр, `js/shared/quietframe.ts`), `user/message` источника `user` без метки поставки — слово человека, говорящий вызов (`assistant/message` с блоком `tool-call`, затем `tool/result` без ошибки), текст — последнее `assistant/message` без вызовов; на `turn/end` с `reason.kind` `completed` ход кадра, потерявший слово, получает слово `TURN` одним сообщением `next-turn`; ход, взявший само это слово, освобождён. Обложка без `turn` в `rituals:` глушит, обложки нет — включён. Только события сессии корня (`root.ts`). Форма событий — по типам установленного `@deepseek-ai/dsh-session` 0.2.2-rc.1 и докам (#10657), живьём не наблюдена; что посланное плагином сообщение возвращается `user/message` с тем же id — допущение.
- **Сторож памяти — неприменим**: своей памяти харнеса у dsh нет — ни в поверхности плагинов (#10657: `agent/pre-step`, `tools/pre-execute`/`post-execute`, `session/event` с `turn/*`, `tool/*`, `compaction/*`), ни в пакетах установленного 0.2.2-rc.1 (ни каталога памяти, ни `MEMORY.md`; память — только подключаемые по выбору MCP-серверы из `config/examples/`, их записи — вызовы MCP, не файлы харнеса). Охранять нечего; появится своя память — пересмотреть.
- `compaction.ts` — слово возврата роли по образцу `js/opencode/compaction.ts`: место из hold-записи, без записи — голое слово (словарь `COMPACTION`).

## Как выбирается стояние

Только hold-запись `*.hold`, написанная мостом MCP ЭТОЙ сессии (правило этапа 3, по ревью этапа 2: единственный взгляд на `agent/created` берёт чужое место — мост сессии ещё не встал): единственный ключ машины или чужая запись того же каталога — чужое место, его кадры не наши. Запись подходит, когда одновременно:

- `client` равен имени клиента, которым dsh представляется мосту в initialize (`clientInfo.name`); наблюдалось руками на 0.2.2-rc.1 — `dsh-mcp-client` (константа `DSH_MCP_CLIENT` в `seat.ts`, живой initialize — случай №5251);
- `cwd` равен `process.cwd()` (через `sameDir`) — место стояло на этом рабочем каталоге;
- `at` не раньше старта плагина — записи, написанные до его загрузки, принадлежат прежним сессиям; и запись жива (не протухла, не `left`).

Место занимает модель на своём первом ходе, позже `agent/created` и часто позже минуты, поэтому место ждут опросом каталога `standings` всю жизнь сессии: в окне прицепления (60 с, тот же шов `ISKRON_WATCHDOG_ATTACH_MS`) — каждую секунду, дальше — раз в 5 с; таймер опроса процесс не держит:

- ровно одна подходящая — ухо прицепляется к её сокету;
- несколько подходящих — глухо, сказано одной громкой строкой (`DSH`-словарь), без угадывания;
- за окно ни одной — сказано один раз, что слуха пока нет, опрос идёт дальше.

После `session/disposed` ожидание снимается. Слова — `js/delivery/words/dsh.ts`; источник сообщений — `CLIENTS.dsh`. Граница ядра: `make check-core` держит каталог чистым (без кириллицы и имени продукта).
