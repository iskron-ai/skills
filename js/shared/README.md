# js/shared — общие границы и протоколы

- `seam.ts`, `seam-host.ts`, `seam-entrance.ts` — локальный шов тонкого моста и демона: кадры, рукопожатие, вход, сессии.
- `snapshot.ts` — типы снимка машины и белый список полей для `status`; сборка по областям — `../bridge/snapshot.ts`, подкоманда — `../cli/status.ts`.
- `scope.ts` — область сессии; `standings.ts` — пути записей и дверей мест.
- `serviceid.ts` — префикс служебных вызовов клиента: не вызов модели; вместе с флагом отличает предварительное место автопосадки.
- `cover.ts` — обложка проекта (плоский YAML-фронтматтер `AGENTS.md`): граф и роль агента для автопосадки корня (`../opencode/rootseat.ts`), язык формы и чей штамп; файл, формы по языкам и штампы — слоя поставки (`COVER`). Чужой штамп без своего — `{ foreign: true }`: не садится и молчит.
- `pulseword.ts` — линия слова сессии о ходе мосту (`iskron/pulse`), одна для плагина OpenCode и расширения pi (#7529): один запрос в полёте, слова за ним сворачиваются в последнее (state и моменты вместе), отказанное — повтором через 2 с, брошенная линия молчит и поздний исход её запроса ничего не трогает. Пробы — `../tests/pulseword.test.mjs`.
- `seatmodel.ts` — место-спутник несёт модель харнесса, не слово агента (#7591): одно правило плагина OpenCode и расширения pi.
- `reposigns.ts` — выровнен ли репозиторий под агента, по трём локальным признакам: обложка (фронтматтер `AGENTS.md` с ключом графа или роли — `cover.ts`; битый — не обложка), хук старта (запись `SessionStart` Claude Code с меткой поставки либо плагин ритуалов OpenCode), штамп iskronify; обложка и штамп — в любой языковой форме поставки (`COVER`), файлы хуков и метки — слоя поставки (`REPO_SIGNS`). Корень — ближайший каталог вверх с `.git` (каталог или файл worktree). Исход зависит от харнесса вызова: `invite` (ни одного признака), `aligned` (обложка, штамп и хук старта этого харнесса — Claude Code или OpenCode; харнессу без хука iskronify, `null`, хук не нужен), `partial` (недостаёт написанного для этого харнесса), `outside` (не репозиторий), `foreign` (штамп чужой поставки, ни своего штампа, ни хука старта — молчание, #8089). Общий для хука Claude Code (`../cli/onboard-hook.ts`) и первого промпта OpenCode (`../opencode/onboardstart.ts`); пробы — `reposigns.test.mjs`.

Слова поверхности — в `../delivery/`, импорт через `../delivery/index.ts`. Пробы шва — `../tests/seam.test.mjs`, снимка — `../tests/status*.test.mjs`.
