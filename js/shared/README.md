# js/shared — общие границы и протоколы

- `seam.ts`, `seam-host.ts`, `seam-entrance.ts` — локальный шов тонкого моста и демона: кадры, рукопожатие, вход, сессии.
- `snapshot.ts` — типы снимка машины и белый список полей для `status`; сборка по областям — `../bridge/snapshot.ts`, подкоманда — `../cli/status.ts`.
- `scope.ts` — область сессии; `standings.ts` — пути записей и дверей мест.
- `serviceid.ts` — префикс служебных вызовов клиента: не вызов модели; вместе с флагом отличает предварительное место автопосадки.
- `cover.ts` — обложка проекта (плоский YAML-фронтматтер `AGENTS.md`): граф и роль агента для автопосадки корня (`../opencode/rootseat.ts`); файл и ключи — слоя поставки (`COVER`).
- `seatmodel.ts` — место-спутник несёт модель харнесса, не слово агента (#7591): одно правило плагина OpenCode и расширения pi.
- `reposigns.ts` — выровнен ли репозиторий под агента, по трём локальным признакам: обложка (фронтматтер `AGENTS.md` с ключом графа или роли — `cover.ts`; битый — не обложка), хук старта (запись `SessionStart` Claude Code с меткой поставки либо плагин ритуалов OpenCode), штамп iskronify; файлы и метки — слоя поставки (`REPO_SIGNS`). Корень — ближайший каталог вверх с `.git` (каталог или файл worktree). Исход: `invite` (ни одного), `aligned` (все), `partial`, `outside` (не репозиторий). Общий для хука Claude Code (`../cli/onboard-hook.ts`) и первого промпта OpenCode (`../opencode/onboardstart.ts`); пробы — `reposigns.test.mjs`.

Слова поверхности — в `../delivery/`, импорт через `../delivery/index.ts`. Пробы шва — `../tests/seam.test.mjs`, снимка — `../tests/status*.test.mjs`.
