# js/shared — общие границы и протоколы

- `clock-notices.ts` — общий безопасный рендер `card_unanswered`/`line_due` из `provenance` платформенного `message` (#10167, провод 0.181.0): белый список серверных фактов, без вычисления часов; тот же список очищает `details` через `cardFrame`. Неизвестные notice остаются на общем пути.

- `open-cards.ts` — проверка серверного `my_open_cards`, `repeat`/`repeat_n` и строки общего рендера (#10167); даты печатаются как присланы, без вычисления возраста. Нет поля или неверная форма — неизвестно, не ноль. Повтор карточки не меняет id доставки и не становится событием графа.

- `spawned-for.ts` — строгая пара приглашение/UUID дела, JSON без повторов ключей, сверка источников и квитанции register (#9959, #6576); общий разбор для моста и OpenCode.

- `graph-receipt.ts` — частная привязка локального `ChannelEvent.seen` к graph-кадру и строгая запись ключей только после вложения служебного текста в контекст. Путь ограничен standings-каталогом собственного authdir; серверные поля кадра не дают права записи. Старый plugin без этого шага не подтверждает вручение в общей `.seen`.

- `graph-inbox.ts` — структурное распознавание и группы мягких вопросов по графу и номеру; `seen.ts/splitBatch` сохраняет ключи вытесненных событий вместе с последней версией до передачи. Через JSON их несёт только `ChannelEvent.marks`, не поля серверного кадра; `carryGraphMarks` восстанавливает внутренний carrier, не пишет seen. Старый сторож marks одиночного кадра не понимает: мост сверяет его обычный `ev:latest` с собственным реестром (`../bridge/graph-retirements.ts`).
- `softbatch.ts` — отделение мягких вопросов из смешанной пачки старого моста до выбора пути харнесом.

- `seam.ts`, `seam-host.ts`, `seam-entrance.ts` — локальный шов тонкого моста и демона: кадры, рукопожатие, вход, сессии.
- `snapshot.ts` — типы снимка машины и белый список полей для `status`; сборка по областям — `../bridge/snapshot.ts`, подкоманда — `../cli/status.ts`.
- `http.ts` — единственная дверь сети моста и CLI (#9972): `namedFetch` и `namedSocket` несут `user-agent: <BRIDGE_NAME>/<VERSION>` из слоя поставки; голый `fetch` в ядре роняет линт. Проба — фейк NKS (`../tests/fake-nks.mjs`) на остановке роняет набор, если запрос пришёл без имени моста.
- `scope.ts` — область сессии; `standings.ts` — пути записей и дверей мест.
- `seatbydir.ts` — место харнесса по каталогу сессии из записей держания на диске, без моста: ровно одно живое, не отпущенное место этого харнесса из этого каталога, иначе `null` — не угадывать. Читает хук Claude Code после сжатия (`../cli/onboard-hook.ts`); пробы — `../tests/compact-hook.test.mjs`.
- `mcpsession.ts` — короткая сессия MCP под собственным ключом моста вне сессии харнеса: initialize, вызовы по имени, DELETE на закрытии (#9174); читают `../cli/preparegraph.ts` и описания запускателей оркестратора (`../bridge/orchestra-launchers.ts`).
- `mindslice.ts` — правила человека в ход (#9817, риски #9818, #9819): readiness учётки, затем один `iskron_search` среза agents,ways личного графа `mind`; строка на правило — имя, номер, фрагмент описания, тело по номеру; каждое слово с меткой «личное» (`MIND_SLICE`, формы прозы — `MIND_ROW`, `MIND_PRESENT`, `MIND_MISSING`); личная память не готова (нет графа или карты человека), признак не прочитан, отказ — одна строка. `sliceIn` находит блок в ответе `iskron_stand` — его кладёт в слово запуска `launch.ts`. Читают мост (`../bridge/standtail.ts`) и плагин OpenCode (`../opencode/mindslice.ts`); пробы — `mind-slice.test.mjs`, `opencode-mindslice.test.mjs`.
- `serviceid.ts` — префикс служебных вызовов клиента: не вызов модели; вместе с флагом отличает предварительное место автопосадки.
- `cover.ts` — обложка проекта (YAML-фронтматтер `AGENTS.md`): граф и роль агента для автопосадки корня (`../opencode/rootseat.ts`) и чей штамп — из блока корневого ключа поставки (#9316), прежняя плоская форма по языкам — переходом; файл, ключ, формы и штампы — слоя поставки (`COVER`). Чужой блок или штамп без своего — `{ foreign: true }`: не садится и молчит.
- `covercontract.ts` — чтение контракта из того же блока/форм штампа, без записи (#9786): известный, чужой, отсутствующий, неверный или неоднозначный. Одно предупреждение на входах Claude/OpenCode start и CLI doctor/prepare; число не меняет допуск ритуалов и не снимает хуки. Пороги и слова — `../delivery/contract.ts`.
- `coverblock.ts` — блок обложки без модели и без YAML-библиотеки: разбор фронтматтера (плоский и блоки), поля `graph`, `holon`, `agent_role`, `contract`, `stamp` и `rituals` (`ritualsOf`: включённые ритуалы поставки, #9341); `coverwrite.ts` — запись блока на место (`writeCover`: идемпотентна, прочие строки и поле `rituals` не трогает) — общая для прогона и подкоманды моста (#9319); пробы — `cover.test.mjs`, `coverwrite.test.mjs`.
- `pulseword.ts` — линия слова сессии о ходе мосту (`iskron/pulse`), одна для плагина OpenCode и расширения pi (#7529): один запрос в полёте, слова за ним сворачиваются в последнее (state и моменты вместе), отказанное — повтором через 2 с, брошенная линия молчит и поздний исход её запроса ничего не трогает. Пробы — `../tests/pulseword.test.mjs`.
- `seatmodel.ts` — место-спутник несёт модель харнесса, не слово агента (#7591): одно правило плагина OpenCode и расширения pi.
- `ritualcover.ts`, `ritualjudge.ts`, `memorypath.ts` — ритуалы поставки (#9319, раздел РИТУАЛЫ): адреса обложки репо, включающие их, слово старта по ним (полное или раннего входа, #8018), язык слов — по разделу тела обложки, разделы, которые слова цитируют, — заголовки файла по роду (`SECTIONS`, #9351; не узнан — AGENTS.md без раздела), и свой плагин ритуалов OpenCode; пуш и мерж по исходу — правило фильтров jq `skills/iskronify/references/hooks.md` (образец для поставки старше контракта 39; пробы — третий носитель в `ritual-hooks.test.mjs`), сверх него: пуш в ствол, и тихий тоже, говорит слово мержа (#8362, пробы — `rituals-delivery.test.mjs`) — образец этого не знает, к нему не выравнивать; путь в локальной памяти по правилу memory-guard. Общие для `../cli/rituals-hook.ts` и `../opencode/rites.ts`.
- `trunkpush.ts` — пуш в ствол (#8362): цель по отчёту git (`x -> main`), иначе по refspec, иначе по ветке каталога; такой пуш говорит слово мержа (`pushedTo` в `ritualjudge.ts`). Там же разбиение аргументов на слова и вызов git каталога.
- `turnend.ts` — конец хода на вахте (#9342, #9345): какой вызов кладёт слово туда, где его видит человек (дело ask/say/answer/talk, канал send; ответ побудке о живости — status места), метка поставки на тексте, правило «ход кадра потерял слово» — не будят консоль, где человек писал в последние 30 минут, и строка до 280 знаков без «?»; имя ритуала в списке обложки — `TURN_RITE`. Общее для `../cli/turnread.ts` и `../opencode/turnend.ts`.
- `quietframe.ts` — текст кадра, где месту ничего не адресовано (#9345, #6574): только строки счёта дел «тебе 0» под шапкой лежалой пачки или без неё, читается обратно из слов `FRAME_TEXT` и `STALE` без пробелов (сторож переносит длинные строки); такой кадр ход кадра не начинает.
- `frame-format.ts` — поддержка компактного счёта читателем (#9345, #9674): объявление `compact-counts` в initialize и выбор формата в области сессии. Без объявления мост сохраняет прежний счёт; сторож также консервативен по умолчанию, явный `--compact-counts` означает подтверждённую поддержку его читателем.
- `reposigns.ts` — выровнен ли репозиторий под агента, по трём локальным признакам: обложка (блок поставки во фронтматтере `AGENTS.md` либо прежний ключ графа или роли — `cover.ts`; битый — не обложка), хук старта (запись `SessionStart` Claude Code с меткой поставки либо плагин ритуалов OpenCode), штамп iskronify (`contract` и `stamp` блока либо прежняя строка в любой языковой форме, `COVER`), файлы хуков и метки — слоя поставки (`REPO_SIGNS`). Корень — ближайший каталог вверх с `.git` (каталог или файл worktree). Исход зависит от харнесса вызова: `invite` (ни одного признака), `aligned` (обложка, штамп и хук старта этого харнесса — Claude Code или OpenCode; харнессу без хука iskronify, `null`, хук не нужен, и блоку с `graph`, `holon`, `agent_role` — старт несёт поставка), `partial` (недостаёт написанного для этого харнесса), `outside` (не репозиторий), `foreign` (штамп чужой поставки, ни своего штампа, ни хука старта — молчание, #8089). Общий для хука Claude Code (`../cli/onboard-hook.ts`) и первого промпта OpenCode (`../opencode/onboardstart.ts`); пробы — `reposigns.test.mjs`.

Слова поверхности — в `../delivery/`, импорт через `../delivery/index.ts`. Пробы шва — `../tests/seam.test.mjs`, снимка — `../tests/status*.test.mjs`.
