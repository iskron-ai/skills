# iskron-ai/skills

Агентские скилл-бандлы для работы с **NKS** (Nyāya Knowledge System) — методом структурного вопрошания над направленным графом. Это скиллы Claude Code, которые учат агента читать, писать, проектировать и ткать граф NKS через MCP-тулы `iskron_*`, подключённые к `mcp.iskron.ru`.

Тексты скиллов — русские, выведенные из канона графа методологии (не перевод: ре-деривация).

## Скиллы

| Скилл | Что делает |
|---|---|
| **entry** | Протокол ориентации и чтения — вход в граф, опознавание мотивации, поиск, углубление. |
| **writing** | Дисциплина записи узлов — именование (正名), модусы, given_as, стрелки. |
| **design** | Проектирование систем — обратное выведение, прямое ткачество, анализ рисков, импульс доставки. |
| **weaving** | Семантическое завершение существующего графа — замыкание жизненных циклов, починка натяжений. |
| **inquiry** | Жизнь вимарши — якорение, разрешение, закрытие, парковка, кристаллизация, привязка к превращению. |
| **assembly** | Ритуал 時-цикла — различить превращения (bianhua) графа и произвести 形, карту сборки. |
| **integrity** | Целостность превращения — волновой фронт воздействия телоса и обратный claim-аудит прозы. |
| **intake** | Впуск внешнего слова (шабды) в граф — форма→тип, модус по виду источника, дедуп, якорение, сверка. Источник-независим. |
| **vahta** | Вахта — собственный цикл агента: инбокс роли и живой канал, дешёвый дежурный такт и дорогой рабочий; работа кончается интеграцией, не коммитом. |
| **collaborate** | Сотрудничество делателей поверх контуров — распознать границу, найти делателя, адресовать, разбудить, ждать под пределом, сойтись или эскалировать, закрыть записью. Граф — запись; канал — побудка. |
| **foreman** | Бригадир — ведение бригады делателей над одним полем работы: ставит, замечает вставших, собирает решения владельцу, доносит ответы, докладывает дельту. |
| **feedback** | Опыт сессии, записанный туда, где по нему можно действовать, — случай, не мнение: жанр, цитата правила, механизм, критерий закрытия. |
| **establish-mcp** | Достижение графа, когда харнесс не может: лестница «нативно или мост» и iskron-bridge — stdio→HTTP MCP-мост с полным OAuth-флоу. |
| **reality-audit** | Терминальная приёмка поведенческой работы — свидетельствование: канонический носитель, исполняемый фальсификатор, вердикт = код выхода. |
| **minding** | Ум пользователя в графе — личный граф @handle/mind: вспоминание и запись рефлексом, бутстрап и сверка памяти. |
| **methodology-work** | Работа над самим графом методологии. Живёт только в этой дистрибуции. |
| **iskronify** | Приведение репозитория к стандарту `AGENTS.md` — генерация конфига, ритуалы сессий, гейт качества. Идемпотентен: перезапускай после дрейфа. |
| **product-roadmap** | Продуктовый роадмап GitHub-репозитория (или мультирепо-продукта) из issues и PR через граф рассуждений. Композирует iskronify + intake + assembly. |

## Установка

### Быстрее всего: отдай установку своему агенту

Вставь этот промпт в агента, которым уже пользуешься (Claude Code, Cursor, Codex):

```
Установи мне скиллы iskron: скачай https://raw.githubusercontent.com/iskron-ai/skills/main/SETUP.md
и выполни все шаги автономно, спросив мой токен, когда понадобится.
```

[`SETUP.md`](SETUP.md) — установщик, исполняемый агентом: обычный markdown, можно прочесть заранее. Ручные пути ниже.

### Плагин Claude Code (рекомендуется)

```sh
/plugin marketplace add iskron-ai/skills
/plugin install iskron@iskron
```

Все скиллы ставятся вместе под плагином `iskron` (явный вызов — `/iskron:design` и т.п.; модельный вызов работает сам).

**Обновление.** `iskron` — сторонний marketplace, поэтому — в отличие от официального маркетплейса Anthropic — он **не** автообновляется. Всё неофициальное обновляется вручную:

```sh
/plugin marketplace update iskron
/reload-plugins
```

Или один раз включи автообновление: `/plugin` → **Marketplaces** → `iskron` → **Enable auto-update** (тогда плагин освежается при старте).

### Портируемая установка (другие агенты, claude.ai)

Для Claude Code предпочитай плагин выше — он неймспейсит скиллы (`/iskron:design`) и держит их изолированными. Способы ниже ставят **плоско**, в общую директорию скиллов под голыми именами (`design`, `writing`, …) — возможны коллизии с одноимёнными скиллами других паков; в этом случае переименуй целевую директорию. На установку плагина они не влияют.

**npx** (Claude Code, Cursor, Codex, …):

```sh
npx skills add iskron-ai/skills --all --agent claude
```

`--agent claude` кладёт скиллы в `~/.claude/skills/` (то, что сканирует Claude Code), а не в дефолтную `~/.agents/skills/`.

**claude.ai (плагин целиком):** каждый [релиз](https://github.com/iskron-ai/skills/releases/latest) начиная с v3.2.0 несёт `iskron.zip` — архив плагина. Загрузи его как плагин в claude.ai; для обновления загрузи ассет более свежего релиза — то же имя плагина перезаписывает установленную копию. Автообновления у этого канала нет: установлено то, что ты загрузил последним (его `version` лежит в `.claude-plugin/plugin.json` внутри архива).

**Отдельные скиллы / вручную:** каждый `*.skill` — закоммиченный zip-бандл (`<name>/SKILL.md`). Загрузи его как Skill в claude.ai или распакуй в свою директорию скиллов:

```sh
unzip design.skill -d ~/.claude/skills/
```

## Устройство и сборка

- `skills/<name>/SKILL.md` — **источник истины.**
- `*.skill` — закоммиченные **производные** бандлы. Не редактируются руками; `make build` (или просто коммить с включённым хуком `make hooks` — он пересобирает их на каждом коммите).
- `make plugin` — архив плагина для claude.ai (`dist/iskron.zip`); CI прикладывает его к каждому релизу.
- `.claude-plugin/marketplace.json` + `.claude-plugin/plugin.json` — манифесты плагина; версию пишет release-please при мерже релизного PR.
- `.mcp.json` — MCP-эндпоинт iskron: `https://mcp.iskron.ru/`.
- `DERIVATION.md` — карта деривации скиллов из канона методологии + языковой контракт.
