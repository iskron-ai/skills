# Карта деривации — скиллы ← канон methodology

Скиллы — **портируемая проекция** реалма methodology: канон живёт в графе, скиллы несут его агентскую выжимку inline (скиллы реалм-агностичны и не могут указывать в граф — см. конвенции AGENTS.md). Поэтому дрейф структурен: когда канонический ориентир меняется, спроецированные секции сами НЕ обновляются. Эта карта — чек-лист ре-проекции для мейнтейнера.

**Ритуал:** после любого пуша, меняющего канонический ориентир methodology, пройди строку — ре-спроецируй каждую перечисленную секцию из текущего тела ориентира, прогони `make check`, просмотри дифф. Та же дисциплина audit-classify-act, что iskronify применяет к AGENTS.md, — применённая к скиллам.

Файл обращён к мейнтейнеру (доступ к реалму предполагается); seq графа здесь разрешены — внутри `skills/` они запрещены.

Авторские продуктовые блоки (superpowers-interop, realm≠repo, пороги вызовов, GitHub-адаптер) канона не имеют и сохранены как авторские.

Ещё две обязанности синхронизации вне таблицы:

- **Поверхность тулов → скиллы** (AGENTS.md: «tool references must be live») — когда сервер за mcp.iskron.ru переименовывает/убирает тул или меняет поведение фабрик, грепни `skills/` по имени тула. Префикс этой поставки — `iskron_*`.
- **superpowers → interop-секция** — `skills/iskronify/references/superpowers-interop.md` несёт собственный чек-лист перепроверки.

Особый статус: **methodology-work живёт только здесь** — в соседней дистрибуции (#844) его нет; канон для него — сам реалм methodology.

Продуктовые скиллы без единого канонического ориентира: **iskronify** и **minding** — их источник — прообразы в соседней дистрибуции (#844) + компоненты канона (аудит-классификация, кристаллизация в §2 minding, дисциплина холонных вопросов); сверять при её обновлениях, ре-деривация по-русски с обогащением семантическими гнёздами. Той же природы **foreman** (методология + живая вахта над параллельными PR), **feedback** (жанровый канон + дисциплина размещения) и **establish-mcp** (транспортный мост `scripts/iskron-bridge.mjs` — код, не проекция канона; сверять при переменах OAuth/MCP-поверхности сервера).
